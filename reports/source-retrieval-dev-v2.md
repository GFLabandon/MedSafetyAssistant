# 来源片段检索开发评测 v2

运行：`conda run -n medsafety python -m evaluation.source_retrieval_contract --output reports/source-retrieval-dev-v2.json`。逐例结果、数据集与清单 SHA-256、目录版本和实现提交见 [JSON 报告](source-retrieval-dev-v2.json)。

评测范围只有 **1 个 FDA 来源章节、3 个片段、9 个开发问题**；词法和本地哈希向量各运行一次，共 18 次。top-1 正确 **16/18**，预期片段的事实关联正确 **16/18**；所有返回项的来源与事实 ID 均满足目录约束（越界 **0/18**）。本地哈希向量是词法特征，不是训练得到的语义 Embedding。这些数字不能表述为独立检索或临床准确率。

**保留的失败：**“对乙酰氨基酚剂量”期望命中剂量说明片段 `:002`，词法和哈希向量都返回重复产品片段 `:001`。返回片段自身的来源和事实关联是合法的，但与该问题不相关，因而附带的 `fact-duplicate-acetaminophen-001` 不能当作这个问题的证据。当前中文关键词只锚定了重复产品提示，无法可靠区分剂量主题。

本轮还修正了片段关联：清单中的文档级 `linked_fact_ids` 仅声明允许的事实，实际检索响应只有含审核锚句的 `:001` 返回该事实 ID；剂量和求助信息片段的关联列表为空。来源检索仍是页面上的独立实验区，不进入 Safety Engine 或正式解释。引入更多经过审核的来源与问题，再评估检索片段是否有资格辅助解释。
