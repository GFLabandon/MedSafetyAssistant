# V1 alpha.4 数据卡

冻结日期：2026-07-25
数据版本：`v1.0.0-alpha.4`

## 用途与范围

该快照用于 MedSafetyAssistant 的工程验证、产品级事实建模和来源可追溯性演示。alpha.4
首次增加一条以具体产品“泰诺”为主体的活动限制事实。它不适合评估真实世界总体用药
安全，不得用于诊断、治疗、停药、换药或剂量决策。

## 相对 alpha.3 的变化

- 来源从 8 条增加到 9 条；
- 上下文从 2 条增加到 3 条，新增 activity context；
- 正式事实从 3 条增加到 4 条；
- 新增泰诺产品级 `ACTIVITY_RESTRICTION`；
- 泰诺药品记录增加官方产品说明书来源；
- 药品/成分记录仍为 5 条；
- 开发样例从 13 条增加到 17 条。

仓库只保存 URL、释义、定位和哈希，不提交原始 PDF。

## 建模边界

- 事实主体是 `medication-tyno-cold-tablet-cn` 对应的具体产品，不是氯苯那敏成分；
- activity context 只在用户明确询问驾驶、高空、机械或精密仪器作业时解析；
- 事实没有外推到感康或其他含相似成分的产品；
- `ORANGE` 是项目沟通策略，不是说明书中的临床严重度等级；
- `reviewed/source_aligned` 表示项目完成来源与字段复核，不表示医生或药师临床审核。

## 评测边界

`eval/safety_engine_dev.jsonl` 含 17 条开发样例，其中 alpha.4 新增两个正例和两个防外推
负例。当前 1.000 指标是共同迭代后的确定性开发回归，不是锁定测试、模型泛化结果或
临床准确率。

基线见
[`baseline-safety-engine-v1-alpha.4.md`](../reports/baseline-safety-engine-v1-alpha.4.md)。

## 完整性校验

```bash
shasum -a 256 -c data/v1/checksums.sha256
python scripts/validate_v1_data.py
```

`checksums.sha256` 冻结 4 个权威 JSON 文件和开发集。后续内容变化必须提升数据版本、
重新生成基线并更新数据卡。

## 已知限制

- 只覆盖一个泰诺产品说明书版本和一个活动场景集合；
- 没有自动同步产品说明书更新；
- 短别名“驾驶”只表达用户明确提及该活动，不推断实际职业或当前状态；
- 范围内未命中不能表达“安全”；
- 来源对齐不能替代临床专家复核。
